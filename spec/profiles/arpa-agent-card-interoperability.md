# ARPA Agent Card Interoperability Profile

This document is retained as a compatibility entry point. The versioned profile for current implementation work is the [ARPA A2A v1.0 Interoperability Profile](arpa-a2a-v1.0-interoperability-profile.md).

The governing rule remains unchanged: external Agent Cards are discovery and routing inputs. Their content MUST NOT be interpreted as verified capability, delegated authority, assurance or governance recognition without separate competent evidence.
