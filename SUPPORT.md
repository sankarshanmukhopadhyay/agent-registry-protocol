# Support

Use GitHub Issues for reproducible defects, specification/documentation inconsistencies, interoperability questions, and bounded change proposals. Include the affected revision/version, expected and observed behaviour, and the smallest useful reproduction or evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

ARPA owns the protocol and repository-local artifacts defined here. Questions that depend on external semantic, assurance, or deployment authorities should be routed to the owning project rather than answered by silently broadening ARPA's scope.
