# Controlled Registries

These files provide machine-readable identifiers used by ARPA artifacts. Additions require documented semantic ownership, collision analysis, security and privacy review, migration impact and conformance vectors. Removal is by deprecation or supersession; identifiers are not silently reassigned.

- `reconstruction-statuses.json` and `historical-effect-codes.json` — controlled historical-resolution vocabularies.

## Candidate hardening registries

- `lifecycle-transitions.json` — normative legal transition graph, authority and precondition metadata.
- `revocation-convergence-statuses.json` — separates publication/propagation from evidenced enforcement convergence.
- `normative-requirements.json` — generated catalogue of BCP 14 clauses with stable content-derived IDs and evidence mappings.
