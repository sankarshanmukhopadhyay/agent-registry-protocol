# End-to-End Scenarios

The scenarios below are executable governance narratives. Each identifies authority, enforcement, evidence and revocation outcomes.

| Scenario | Profile | Primary modules | Primary evidence |
|---|---|---|---|
| Informational agent | A | Core | identity, description digest, lifecycle history |
| Enterprise workflow | B | Relations, Assurance, Evidence | typed operator, assurance and execution receipt |
| Bounded procurement | C | Relations, Authority, Evidence | authority envelope, decision receipt, cascade revocation |
| Healthcare access | D | Authority, Evidence, Federation | purpose/jurisdiction constraints and protected evidence |
| Public-service eligibility | D | Authority, Evidence, Federation | policy version, appeal and restoration |
| Fiduciary analysis | D | Relations, Authority, Evidence | explicit prohibitions and accountable entity |
| Operator change | B-D | Relations, Assurance, Evidence | relationship transition and assurance review |
| Compromised runtime | B-D | Assurance, Evidence | deployment quarantine and enforcement event |
| Stale projection | A-D | Core, Evidence, Federation | lag disclosure and indeterminate result |
| Federation conflict | D | Federation, Assurance, Evidence | recognition policy and conflict evidence |
| Emergency suspension | D | Core, Authority, Evidence | rapid status event, appeal and restoration |
| Delegated action | C-D | Core, Relations, Authority, Evidence | end-to-end resolution, decision, execution and audit |
